# 🚩 Roadmap to Becoming a Red Teamer

**Short Description:**  
A personal, structured roadmap and learning log documenting my journey from foundational cybersecurity skills to professional red teaming.  
This repository includes study notes, lab exercises, write-ups, CTF solutions, and a progress tracker.

---

## 🧠 About

This is *my personal roadmap* toward becoming a **Red Teamer**.  
My focus is on building a strong foundation in:

- **Networking Fundamentals**
- **Operating Systems:** Windows & Linux
- **Programming/Scripting:** Python, Bash, and PowerShell

After mastering the fundamentals, I’ll dive into **offensive security techniques**, including:

- Reconnaissance & Information Gathering  
- Vulnerability Discovery  
- Exploitation & Privilege Escalation  
- Post-Exploitation & Persistence  
- Evasion, Lateral Movement & Defense Evasion

All learning and practice will be done **legally and safely**, using:

- Local Virtual Machines  
- TryHackMe  
- Hack The Box  
- Custom-built Home Labs  

Each exercise will be **documented** with detailed write-ups, screenshots, and methodologies to ensure reproducibility.
